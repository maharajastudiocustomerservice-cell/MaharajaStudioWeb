Intuitive & Powerful Features

Multi-Actor Choreography & Duets

Direct synchronized 2, 3+ character choreography (dance duets, grapples, shared lifts, combat finishers) with 0ms frame drift. Mix Humanoid and Generic creature/robot rigs in the exact same sequence.

Dynamic Summons & Lifecycles

Author ephemeral summons (weapons, familiars, dragons, or Stand avatars) with automatic timeline lifecycle nodes (SpawnActor / DestroyActor), bone attachments, and zero-allocation object pooling.

Dynamic Motion Warping

Pre-interaction approach locomotion automatically bridges starting distances, scaling movement speed and adapting to terrain normals so characters arrive at sync spots without foot sliding.

8 Frame-Accurate FX Lanes & Decals

Trigger pooled audio, particle systems, surface decals, VFX Graph, transform splines, spawns, camera shakes, and typed C# script callbacks frame-accurately on the shared timeline.

Cross-Actor Prop & FX Handover

Transfer weapons, torches, and spell effects between characters with phase-aware Scene View gizmos, interactive floating HUD bar, and real-time auto-keying.

Post-Export Interaction Overrides

Modify character body spacing (eliminating monster mesh clipping), swap clips, and fine-tune 4 dynamic alignment foldouts with 16px granular toggles—zero re-exporting and zero code modifications.

High-Performance Runtime (Zero GC)

Powered by Unity's low-level PlayableGraph API with 1-line async playback (MSMotionInteraction.Play), on-demand layers, dynamic avatar rebinding, and pre-warmed pooling.

Built-in Clip & Animation Editor

Extract FBX model animations into editable local .anim assets in 1 click. Crop/scale ranges, smooth curves (Median/Gaussian), remove redundant keys, and auto-key with live ghost preview.
