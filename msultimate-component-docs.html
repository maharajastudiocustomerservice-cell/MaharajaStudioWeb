[ComponentBioluminescence]

Renders drifting and pulsing bioluminescent deep-sea organisms across the component card background with fluid organic motion.

1. Overview & Value Proposition

What it does: [ComponentBioluminescence] immerses the component inspector in an ethereal deep-sea ambiance. Operating via UI Toolkit vector painters in ComponentSlot.ContentOverlay, it renders an animated colony of floating luminous plankton organisms (OrganismCount = 18, clamped between 8 and 30 for performance). Organisms drift gracefully across the card surface with fluid noise (DriftSpeed = 0.5f), while pulsing their luminescence with harmonic breathing rhythms (PulseRate = 1.2f). Developers can customize organism glow hue (GlowColor, defaulting to cyan #06B6D4), colony density, and motion tempo.

The Problem: Deep-sea creatures, alien flora, fungal spore ecosystems, and enchanted oceanic artifacts look lifeless in standard flat gray Unity inspector panels. Developers miss the mysterious underwater atmosphere during script tuning.

The Solution: Decorating biological and oceanic systems with [ComponentBioluminescence]:

  • Fluid Organic Drift: Simulates underwater micro-currents with organic drifting velocities across all organism nodes.
  • Harmonic Luminescence Breathing: Each organism pulses independently in luminance and radius based on individual phase offsets.
  • Configurable Colony Density: Scale organism count between 8 and 30 nodes with high editor performance.
  • Background Layer Default: Placed in ContentOverlay with PickingMode.Ignore, ensuring all standard Unity controls remain fully interactable.

2. Quick Start

csharp
using UnityEngine;
using MaharajaStudio.MSUltimate.ComponentDesigner;

[ComponentBioluminescence(glowColor: "#22D3EE", organismCount: 22, driftSpeed: 0.6f)]
public class AbyssalFloraSporeGenerator : MonoBehaviour
{
    public float sporeEmissionRate = 15f;
    public float illuminationRadiusMeters = 8.5f;
    public bool isPhosphorescentFloraMature = true;
}

The Solution: Decorating astrophysics and void systems with [ComponentBlackHole]:

What it does: [ComponentCircuitFlow] transforms the component inspector background into an active printed circuit board (PCB). Injected into ComponentSlot.ContentOverlay, it renders geometric circuit trace pathways (TraceDensity = 8) mapped across the card surface. Developers can customize trace and packet illumination colors (TraceColor, defaulting to emerald #10B981), density, signal travel speed, and background opacity (Opacity = 0.22f).

The Problem: Hardware drivers, CPU emulation logic, IoT device bridges, microchip controllers, and robotic sensor boards appear plain in standard inspector panels. Developers lack immediate visual cues that convey electronic hardware architectures.

The Solution: Decorating electronic and computing systems with [ComponentCircuitFlow]:

  • Animated Data Pulse Packets: Simulates active microchip electrical bus pathways with moving luminous data packets.

  • Configurable Bus Density: Scale trace count (TraceDensity = 8) and speed (PacketSpeed = 1.4f) to fit any component card.
