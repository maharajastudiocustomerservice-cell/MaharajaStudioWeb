[ComponentAnimatedBorder]

Target: Class Slot: BodyWrapper UI Toolkit Native

Wraps the entire component inspector in a kinetic border frame that smoothly pulses between two designated alternating colors.

Unity Inspector Simulated Preview • NetworkSyncManager.cs

Pulses continuously between Cyan (#00BCD4) and Purple (#E040FB).

1. Overview & Value Proposition

What it does: Encapsulates critical MonoBehaviour inspectors with a pulsing animated border. Driven by UI Toolkit's style engine, it calculates a smooth sinusoidal color interpolation without frame stuttering or garbage collection.

The Problem: In massive scenes with hundreds of components, critical managers (like network directors, game state machines, or save controllers) look identical to generic scripts.

The Solution:

  • Instant Visual Priority: Commands immediate attention for high-impact scripts.
  • Hardware Accelerated: Directly animates style values without invalidating layout trees.
  • Safe Lifecycle: Automatically pauses when the inspector window is minimized or hidden.

2. Quick Start Example

using UnityEngine;
using MaharajaStudio.MSUltimate.ComponentDesigner;

[ComponentAnimatedBorder("#00BCD4", "#E040FB", Width = 2.5f, Radius = 8f, Speed = 2.0f)]
public class NetworkSyncManager : MonoBehaviour
{
    public string serverAddress = "127.0.0.1";
    public int port = 7777;
}

[ComponentHeaderButton]

Target: Class Allow Multiple: Yes Slot: BeforeContent

Adds clickable action buttons directly inside the component header bar to invoke MonoBehaviour methods with custom labels, icons, and colors.

Unity Inspector Simulated Preview • DungeonRoomGenerator.cs
🏰 Dungeon Generator
Dungeon Seed

1. Overview & Value Proposition

What it does: Pins operational trigger buttons directly at the top of the component header for instant access without scrolling through long inspector fields.

The Problem: Testing routines like spawning items, re-baking world seeds, or purging pools requires scrolling through 50+ variables to reach action buttons.

The Solution:

  • Header Pinning: Keeps critical buttons pinned at the top of the inspector card.
  • Multi-Button Docking: Supports chaining multiple buttons side-by-side with AllowMultiple = true.
  • Custom Iconography: Supports expressive emojis or icons and custom hex colors.

2. Quick Start Example

using UnityEngine;
using MaharajaStudio.MSUltimate.ComponentDesigner;

[ComponentHeaderButton("RebuildDungeon", Label = "Rebuild", Icon = "🔄", Color = "#10B981")]
[ComponentHeaderButton("ClearMonsters", Label = "Purge", Icon = "💀", Color = "#EF4444")]
public class DungeonRoomGenerator : MonoBehaviour
{
    public int dungeonSeed = 1337;

    public void RebuildDungeon()
    {
        Debug.Log("Rebuilding dungeon with seed: " + dungeonSeed);
    }

    public void ClearMonsters()
    {
        Debug.Log("Purging all active monsters.");
    }
}
