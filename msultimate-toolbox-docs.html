[ConsoleCommand] & Advanced Console Pro

Target: Method (static) Tool: Advanced Console Reflection Auto-Bind

Registers static C# methods as invokable developer console commands within the Advanced Runtime Console overlay, supporting argument deserialization, categories, and fuzzy autocomplete.

In-Game Runtime Console Overlay • [F1 Toggle]
> spawn_item sword_legendary 1
[14:32:05] [Combat] Spawned item 'sword_legendary' x1 at player position.
> god_mode true
[14:32:11] [Cheats] Invulnerability enabled for local player.
> Tab to Complete

1. Overview & Value Proposition

What it does: Turns static C# methods into executable console commands with zero manual registry setup. Typing into the in-game developer console provides fuzzy search, command syntax help, and auto-conversion of string arguments into C# types.

The Problem: Building custom in-game consoles requires writing manual argument dispatchers, maintaining fragile string dictionaries, and constantly updating autocomplete registries.

The Solution:

  • Zero-Boilerplate Reflection: Automatically discovers decorated static methods at runtime startup.
  • Automatic Argument Conversion: Parses integers, floats, booleans, strings, and Vector3 coordinates automatically.
  • Categorized Autocomplete: Groups commands into clean tabs (e.g. Combat, Network, Cheats).

2. Quick Start Example

using UnityEngine;
using MaharajaStudio.MSUltimate.Runtime;

public static class DebugCommands
{
    [ConsoleCommand("heal_player", "Restores the local player to full health.", Category = "Player")]
    public static void HealPlayer()
    {
        Debug.Log("Player restored to full health.");
    }

    [ConsoleCommand("give_gold", "Grants gold currency to player inventory.", Category = "Economy", Usage = "give_gold ")]
    public static void GiveGold(int amount)
    {
        Debug.Log($"Granted {amount} gold to inventory.");
    }
}
