# [OnAfterSave]

> Automatically executes a C# callback method immediately after a scene or asset is saved to disk.

---

## 1. Overview & Value Proposition

**What it does:**
Triggers a method automatically right after you save an asset or scene (`Ctrl+S`).

**The Problem:**
In standard Unity, running code after a scene or ScriptableObject is saved requires writing an `AssetModificationProcessor` or `UnityEditor.SceneManagement` listener script. This separates your logic from the MonoBehaviour itself, making simple tasks like updating build stamps, writing dirty data to JSON, or logging save confirmations messy.

**The Solution:**
Add `[OnAfterSave]` above any method or field in your component:
- **Automatic Post-Save Trigger:** Runs seamlessly whenever the developer saves the current scene or asset.
- **Self-Contained Logic:** Keep all save-related cleanup code inside the relevant MonoBehaviour or ScriptableObject.
- **Cache Invalidation:** Perfect for refreshing asset registries, syncing data with disk, or clearing dirty flags.
- **Zero Runtime Overhead:** Stripped out of player builds; only active in the Unity Editor.

---

## 2. Quick Start

```csharp
using UnityEngine;
using MaharajaStudio.MSUltimate.Runtime;

public class WorldSettings : MonoBehaviour
{
    public string lastSavedTimestamp;

    [OnAfterSave]
    private void OnSaved()
    {
        lastSavedTimestamp = System.DateTime.UtcNow.ToString("yyyy-MM-dd HH:mm:ss");
        Debug.Log("World settings successfully saved!");
    }
}
```

| Specification | Value |
| :--- | :--- |
| **Package** | MSUltimate Core |
| **Attribute Target** | `AttributeTargets.Method | AttributeTargets.Field | AttributeTargets.Property` |
| **Supported Types** | Parameterless methods |
| **Allow Multiple** | `true` |
| **Inherited** | `true` |

## 4. Constructors & Signatures

```csharp
public OnAfterSaveAttribute()
public OnAfterSaveAttribute(string methodName)
```
- **`methodName`**: Optional method name to invoke when applying the attribute on a field or property.

---

## 5. Properties & Customization Options

| Property | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `MethodName` | `string` | `null` | Optional method name to invoke when applied at the field/property level. |
| `Order` | `int` | `0` | Execution order priority among multiple lifecycle callbacks. |

## 6. Production-Grade Example

```csharp
using UnityEngine;
using MaharajaStudio.MSUltimate.Runtime;

[CreateAssetMenu(fileName = "GameEconomyConfig", menuName = "Config/Game Economy")]
public class GameEconomyConfig : ScriptableObject
{
    [Header("Economy Data")]
    public float goldMultiplier = 1.25f;
    public int startingCoins = 500;

    [ReadOnly]
    public string lastExportHash;

    [OnAfterSave]
    private void ExportToCloudBackup()
    {
        lastExportHash = System.Guid.NewGuid().ToString("N");
        Debug.Log($"[EconomyConfig] Exported save snapshot: {lastExportHash}");
    }
}
```

## 7. Stacking & Compatibility Matrix

- **Pairing with `[OnBeforeSave]`:** Pair together to create comprehensive pre-save validation and post-save confirmation pipelines.
- **Pairing with `[ReadOnly]`:** Safely displays timestamps, hashes, or audit information generated by the save callback.
- **Layouts:** Functions cleanly inside `[BoxGroup]`, `[TabGroup]`, and custom inspector layouts.
