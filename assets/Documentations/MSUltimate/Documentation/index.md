# MSUltimate Documentation Hub

> **The Ultimate AAA Inspector & Tooling Architecture for Unity.**  
> Built for Unity 6 (6000.x)+.

---

## Welcome to MSUltimate
MSUltimate elevates the Unity Inspector from a plain serialization window into a responsive, beautiful, high-efficiency authoring environment. Designed for enterprise production pipelines, MSUltimate delivers zero-boilerplate attributes, dynamic layout groups, scene debug overlays, and deep editor tooling.

👉 **New to the ecosystem?** Read the [**Ecosystem & Edition Comparison Guide**](packages-comparison.md) for a comprehensive breakdown of Community, Pro, and Addon packages.

## Modules in this Suite
- **MSUltimate Core** — 156 fundamental attributes, serializers, types, and windowing framework.
- [**Animated Attributes**](../Addons/MSUltimate-AnimatedAttributes/Documentation/index.md) — 87 reactive visual feedback and motion attributes.
- [**Component Designer**](../Addons/MSUltimate-ComponentDesigner/Documentation/index.md) — 75 header cards, themes, and aesthetic styling attributes.
- [**Hierarchy Designer**](../Addons/MSUltimate-HierarchyDesigner/Documentation/index.md) — 83 hierarchy enhancement and telemetry attributes.
- [**ToolBox Vol. 1**](../Addons/MSUltimate-ToolBox-Vol1/Documentation/index.md) — Advanced Console, History Track, Lifetime Track, and Live Track.
- [**Validation Module**](../Addons/MSUltimate-ValidationModule/Documentation/index.md) — 39 real-time validation attributes and project scan window.
- [**Inspector Customizer**](../Addons/MSUltimate-InspectorCustomizer/Documentation/index.md) — Template authoring and UI Toolkit theme skins.

## Editor Windows & Tools Directory
All suite windows are centralized under Unity's top menu: `Tools > Maharaja Studio > MSUltimate > Windows`

| Window Name | Menu Path | Module | Purpose |
| :--- | :--- | :--- | :--- |
| **Setup & Compatibility Wizard** | `.../Windows/Setup & Compatibility Wizard` | Core | First-run setup, dependency checks, and onboarding. |
| **Inspector Layout Settings** | `.../Windows/Inspector Layout Settings` | Core | Global layout padding, colors, fonts, and animation settings. |
| **Asset Manager** | `.../Windows/Asset Manager` | Core | Centralized CRUD catalog for `[ManageableAsset]` ScriptableObjects. |
| **Scene Debug Overlay** | `.../Windows/Scene Debug Overlay` | Core | Master control panel for scene view gizmo and handle overlays. |
| **Validation Window** | `.../Windows/Validation Window` | Validation | Project-wide batch validation scanner and 1-click autofix engine. |
| **Component Designer Studio** | `.../Windows/Component Designer Studio` | Component Designer | Interactive styling workbench for component cards and headers. |
| **Game Systems Database** | `.../Windows/Game Systems Database` | Component Designer | Visual registry and browser for game system data architectures. |
| **Inspector Customizer** | `.../Windows/Inspector Customizer` | Customizer | Main visual inspector customization workbench. |
| **Makeover Graph Editor** | `.../Windows/Makeover Graph Editor` | Customizer | Node-based visual graph editor for compound inspector makeovers. |
| **Template & Recipe Manager** | `.../Windows/Template & Recipe Manager` | Customizer | Author and manage reusable makeover templates and recipes. |
| **Inspector Customizer Settings** | `.../Windows/Inspector Customizer Settings`| Customizer | Customizer engine preferences and baking options. |
| **LiveTrack Dashboard** | `.../Windows/LiveTrack Dashboard` | ToolBox Vol. 1 | Real-time scene telemetry HUD and floating oscilloscope graphs. |
| **Advanced Console** | `.../Windows/Advanced Console` | ToolBox Vol. 1 | High-throughput structured log analyzer and memory profiler tags. |
| **HistoryTrack Window** | `.../Windows/HistoryTrack Window` | ToolBox Vol. 1 | Visual Undo/Redo timeline and object serialization diffs. |
| **Object Lifetime Tracker** | `.../Windows/Object Lifetime Tracker` | ToolBox Vol. 1 | Allocation tracker, memory leak detector, and lifecycle profiler. |
