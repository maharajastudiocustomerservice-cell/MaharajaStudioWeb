# MSUltimate - Component Designer Documentation

> **Next-Generation Component Cards, Visual Themes, Header Controls, and Aesthetic Shells.**
> Standalone Addon for Unity 6 (6000.x)+.

---

## Overview
MSUltimate Component Designer empowers developers and technical artists to transform raw MonoBehaviour inspectors into bespoke design systems. From cyber terminals and blueprints to glassmorphism cards and atmospheric VFX headers, Component Designer provides 75 visual styling attributes.
