# MSUltimate - Component Designer Documentation

> **Next-Generation Component Cards, Visual Themes, Header Controls, and Aesthetic Shells.**
> Standalone Addon for Unity 6 (6000.x)+.

---

## Overview
MSUltimate Component Designer empowers developers and technical artists to transform raw MonoBehaviour inspectors into bespoke design systems. From cyber terminals and blueprints to atmospheric VFX headers and status bars, Component Designer provides 74 concrete visual styling attributes (75 attribute classes including the base `[Component]` contract).
