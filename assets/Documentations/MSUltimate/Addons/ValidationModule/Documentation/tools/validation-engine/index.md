# Validation Engine Window Manual

> Project-wide and scene-wide asset validation scanner with batch auto-fix capabilities.

## Access & Launch
- **Main Window:** `Tools > Maharaja Studio > MSUltimate > Windows > Validation Window`
- **Folder Quick Scan:** Right-click any folder in Project view $\rightarrow$ `Maharaja Studio > MSUltimate > Validate Selected Folder`

---

## Capabilities & Workflows
- **One-Click Project Scan:** Audits scenes, prefabs, ScriptableObjects, and materials across the entire repository.
- **Categorized Issue Grid:** Groups issues by Critical, Warning, and Info with direct object pinging.
- **Batch Autofix:** Executes automated remediation scripts (e.g. restoring default layers, linking references).
