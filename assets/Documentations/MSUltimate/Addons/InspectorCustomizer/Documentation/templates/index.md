# Inspector Customizer - UXML Templates Manual

> Authoring and binding custom UI Toolkit `.uxml` and `.uss` stylesheets to Unity Inspectors.

---

## Capabilities & Workflows
- **Visual Element Binding:** Binding Unity serialized properties to custom UXML tags via property paths.
- **Template Inheritance:** Extending base template cards with specialized header and footer components.
- **Hot-Reload:** Live style preview when editing `.uss` in external text editors.
