# Inspector Customizer - Themes & Styling Tokens Manual

> Global color themes, dark/light mode customization, typography scales, and CSS variable injection.

---

## Capabilities & Workflows
- **Theme Switcher:** Switch between Cyberpunk, Nord, Solarized, Clean Dark, and High Contrast.
- **Custom Token Overrides:** Redefine primary accents, background card tints, and border radii.
- **Exporting Themes:** Package custom theme stylesheets as portable ScriptableObject assets.
