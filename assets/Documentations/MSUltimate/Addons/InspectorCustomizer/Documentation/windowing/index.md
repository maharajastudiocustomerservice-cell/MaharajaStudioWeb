# Inspector Customizer - Windowing System Manual

> Standalone multi-inspector windows, floating utility trays, and dockable property dashboards.

## Access & Launch
- **Inspector Customizer:** `Tools > Maharaja Studio > MSUltimate > Windows > Inspector Customizer`
- **Makeover Graph Editor:** `Tools > Maharaja Studio > MSUltimate > Windows > Makeover Graph Editor`
- **Template & Recipe Manager:** `Tools > Maharaja Studio > MSUltimate > Windows > Template & Recipe Manager`
- **Customizer Settings:** `Tools > Maharaja Studio > MSUltimate > Windows > Inspector Customizer Settings`
- **Component Context Menu:** Right-click Component header $\rightarrow$ `MSUltimate > Open in Inspector Customizer...`

---

## Capabilities & Workflows
- **Multi-Inspector Docking:** Open and lock multiple target components side-by-side.
- **Floating Mini-Inspectors:** Compact borderless floating inspectors for focused asset editing.
- **Window Layout Presets:** Save and restore customized editor window layouts.
