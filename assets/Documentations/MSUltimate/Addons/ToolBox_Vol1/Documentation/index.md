# MSUltimate - ToolBox Vol. 1 Documentation

> **Essential Production Power Tools: Advanced Console, History Tracker, Lifetime Inspector, and Live Telemetry.**
> Standalone Addon for Unity 6 (6000.x)+.

---

## Overview
MSUltimate ToolBox Vol. 1 is an enterprise utility suite addressing the most common developer bottlenecks in large-scale Unity projects: logging noise, undo/redo state tracking, GameObject memory leaks, and real-time field telemetry.

## Included Systems
| Tool / System | Type | Description | Index Link |
| :--- | :--- | :--- | :--- |
| **Advanced Console** | Editor Window | High-speed log analysis, multi-tag filtering, memory profiler tags, and clean stacktraces. | [Open Manual](tools/advanced-console/index.md) |
| **History Track** | Editor Window | Timeline inspection of Undo/Redo state changes, variable diffs, and serialization history. | [Open Manual](tools/history-track/index.md) |
