# Lifetime Track Manual

> GameObject and asset lifecycle tracker identifying persistent memory leaks, dangling event handlers, and unreleased references.

## Access & Launch
- **Menu Path:** `Tools > Maharaja Studio > MSUltimate > Windows > Object Lifetime Tracker`

---

## Capabilities & Workflows
- **Instance Count Profiler:** Detects runaway instantiation or pooling starvation.
- **Dangling Reference Hunter:** Flags references retained by dead GameObjects.
- **PlayMode Transition Audit:** Verifies clean teardown when exiting PlayMode.
