# Advanced Console System Manual

> High-throughput log manager featuring regex search, memory tag filters, one-click stack trace navigation, and zero-allocation log streaming.

## Access & Launch
- **Menu Path:** `Tools > Maharaja Studio > MSUltimate > Windows > Advanced Console`

---

## Capabilities & Workflows
- **Multi-Category Tagging:** Filter logs by subsystem (e.g. `[Audio]`, `[Net]`, `[AI]`).
- **Clean Stacktraces:** De-clutters internal Unity engine stack frames.
- **Log Export & Sharing:** 1-click export to Markdown or JSON for bug reports.
