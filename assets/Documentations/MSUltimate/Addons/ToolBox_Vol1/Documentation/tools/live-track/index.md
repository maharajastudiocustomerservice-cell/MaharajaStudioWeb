# Live Track Manual

> In-SceneView live telemetry HUD and real-time floating oscilloscope graphs for monitoring runtime variables.

## Access & Launch
- **Menu Path:** `Tools > Maharaja Studio > MSUltimate > Windows > LiveTrack Dashboard`

---

## Capabilities & Workflows
- **Floating In-Scene HUD:** Observe values floating above GameObjects in SceneView without glancing at Inspector.
- **Oscilloscope Waveforms:** Live graph plotting floats/ints over time (e.g. velocity, health, AI states).
- **Multi-Object Comparison:** Pins graphs side-by-side for balance tuning.
