# History Track Manual

> Timeline-based inspection of Undo/Redo operations, variable changes, and serialization diffs.

## Access & Launch
- **Menu Path:** `Tools > Maharaja Studio > MSUltimate > Windows > HistoryTrack Window`

---

## Capabilities & Workflows
- **Visual Diff Timeline:** Shows who changed what and when in the current editor session.
- **Rollback to Snapshot:** Restore prior object states without losing unrelated scene edits.
- **Serialization Integrity Check:** Verifies dirty flags and disk persistence.
