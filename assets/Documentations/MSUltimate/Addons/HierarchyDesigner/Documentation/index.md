# MSUltimate - Hierarchy Designer Documentation

> **Transform the Unity Hierarchy into an Informative, Beautiful, and Diagnostic Game Architecture Tree.**
> Standalone Addon for Unity 6 (6000.x)+.

---

## Overview
MSUltimate Hierarchy Designer revolutionizes Unity's native Hierarchy window. It provides visual folders, tree branch connectors, component icon badges, active/visibility toggles, live memory/draw call telemetry, lock icons, and rich typography.
