ScriptableObject & Prefab Studio

Manage game databases at spreadsheet speed

Scriptable Studio Pro replaces slow, single-file Inspector workflows. View and edit RPG item tables, ability configs, NPC stats, and nested Prefab components in a multi-column grid with custom Undo/Redo tracking.

Prototype 100 virtual items in memory with Create Mode before writing files to disk, or load existing project assets in Edit Mode with math formulas, smart fill, and regex validation.
