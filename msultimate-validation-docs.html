[ValidateNotNull]

Target: Field Severity: Error Engine Scanned

Validates that an object reference, string, or collection is not null or empty, displaying high-contrast alert banners directly in the Inspector and surfacing warnings in the Project Scanner.

Unity Inspector Simulated Preview • PlayerInventory.cs

1. Overview & Value Proposition

What it does: Eliminates null reference exceptions by asserting that field references are never left unassigned. It detects missing assets, empty strings, and zero-length arrays before you hit Play.

The Problem: Null references account for over 70% of runtime bugs in Unity projects. Standard Unity performs zero checks on unassigned fields in the inspector.

The Solution:

  • Deep Null & Empty Detection: Setting FailOnEmpty = true additionally catches empty string IDs and zero-element collections.
  • Direct Inspector Alerts: Renders high-contrast inline error cards.
  • 1-Click Project-Wide Scan: The Validation Module window discovers all unassigned fields across the entire project in 1 click.

2. Quick Start Example

using UnityEngine;
using MaharajaStudio.MSUltimate.ValidationModule;

public class PlayerInventory : MonoBehaviour
{
    [ValidateNotNull("Item database asset must be assigned.")]
    public ScriptableObject itemDatabase;

    [ValidateNotNull("Character display name cannot be null or empty.", FailOnEmpty = true)]
    public string characterName = "Hero";
}
