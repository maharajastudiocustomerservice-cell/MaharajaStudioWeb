1. Overview & Value Proposition

What it does: Rather than manually writing dozens of C# attributes by hand across thousands of lines of code, the Template Engine scans class fields and methods, evaluates customizable rules, and applies rich layouts, progress bars, group boxes, foldouts, sliders, and interactive action buttons non-destructively.

Key Advantages:

  • Zero Source Code Pollution: Prototype layouts and theme groups without dirtying git working trees.
  • 1-Click Presets: Pre-packaged with 8 tailored game domain presets (RPG, Sci-Fi Shooter, Vehicles, WorldGen, Audio, AI, UI).
  • Undo/Redo Integrated: Fully registered in Unity's native Undo stack.
  • Optional C# Code Baker: When satisfied, bake virtual layout rules directly into permanent C# attributes.

UXML & USS Theme Tokens Injector

Architecture: UI Toolkit Theme Tokens USS Injection

Inject custom UI Toolkit stylesheets (USS) and structured templates (UXML) into any component inspector, enabling custom branding, dark/light/cyberpunk tokens, and studio themes.

1. Core Concepts

The Theme Token system maps custom color tokens and typography variables directly into Unity UI Toolkit's VisualElement root. You can switch between built-in dark, light, obsidian, and cyberpunk themes globally or per-component.
