Stop digging through nested folders and hierarchies

Object Finder Pro turns your Unity project into a searchable database. Filter by live public component properties, polycounts, texture dimensions, memory footprints, acronym matching (pc → PlayerController), and references across unloaded scenes without freezing the editor.

Version 2.0 adds typo-tolerant Fuzzy Search, Exact Match, an In Root GameObject scope for prefab and skeleton inspection, renameable favorites, and full keyboard navigation across selector windows.

Search workflows & extensible filters

Engineered for rapid debugging, template verification, and large-project refactoring

Smart search query language

Filter by component properties (comp(Light).intensity:>5), tags, layers, negative exclusions (rock -moss), OR lists, polycount, texture width, and memory size.

Asynchronous non-blocking engine

Searches execute in the background with real-time streaming results and progress feedback so massive scenes stay responsive.

Find all references & unloaded scenes

Trace every usage of an asset or component across scenes, prefabs, and ScriptableObjects—even inside scenes that are not currently open.

Multi-component & signature filters

Match objects containing a specific set of components, or require an exact component signature to validate prefab templates, plus 35+ ScriptableObject custom filters.
